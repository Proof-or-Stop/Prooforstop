## Key Insights
The CJK-detection already exists in packages/main/src/handlers/english-artifact-gate.ts (the REVIEW->TEST english-artifacts gate from B-5f42). The fix runs that SAME predicate at AUTHORING time: export a shared containsCJK(text) from english-artifact-gate.ts and call it in story_create (story-create.ts) and background_set/background_append (background.ts) to REFUSE non-English author-controlled content (background, checklist title/context/userSees, title, description) BEFORE it is persisted, with a clear field-named message. Reusing the SAME predicate guarantees the early check and the REVIEW->TEST gate AGREE. The scan covers author-controlled artifacts only; never code or runtime files. Common English punctuation like the U+2014 em-dash must NOT be flagged. A working host-B reference exists in scratch worktree /tmp/s4-cjkcreate.

## Solution Tradeoffs
Shift-left vs leave-at-gate: catching CJK at story_create / background_set fails the operator at the moment they author the text, with a precise field+line message, instead of after a full INIT/PLAN round-trip. Reuse vs reimplement: export and reuse the existing predicate so the early check and the gate can never disagree; do NOT hand-roll a second regex. Scope: hook story_create + background_set/append + export the shared predicate + a smoke; do not change the REVIEW->TEST gate behavior or scan anything beyond author-controlled artifacts.
