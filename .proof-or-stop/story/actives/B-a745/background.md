## Solution Tradeoffs
The alternative of shipping identity plus a real selector in one Story was rejected: without an impact index and exclusion proofs a selector would either be unsound or would widen every time anyway, and it would put a set-shrinking code path into the tree before its safety fixtures exist. Reusing the existing static focus tags as the relevance signal was also rejected, because the plan requires focus tags to stay a backward-compatible profile and to be excluded from dynamic relevance. Provisional deterministic ids for legacy commands were chosen over requiring every project to declare ids up front, so existing configurations keep working with a warning instead of breaking.
