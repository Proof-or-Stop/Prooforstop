## Trigger Event
We agreed (2026-06-22) to build Proofbound's flagship "wow" capability — tamper-evident, independently-verifiable autonomy — through the Lattice workflow. The evidence-gating spine already binds every consequential gate decision to code identity (materialHash/headHash/storyFilesHash) + anti-forgery digests (policyHash/commandSetHash) + a receipt identity (command/args/cwd/exit/output digest), and a verify path exists (core/authority-gate-receipt-verifier.ts, the authority_receipt_verify command). But there is no single self-contained shareable receipt BUNDLE for a DONE story, no OFFLINE re-verifier that recomputes the code-identity hashes from the referenced git tree without the Authority server, and the freshness + anti-forgery guarantee (paper contribution C2) is asserted but never adversarially demonstrated.

## Key Insights
The most defensible "wow" is "you cannot lie to the gate, and anyone can verify the gate's verdict themselves." It is a Tier-A soundness property, NOT a Tier-B comparative rate — so its evidence is an adversarial CONTRACT TEST (every tamper class rejected; authentic accepted; 0 false-accept), not an A/B with confidence intervals. Most primitives already exist (the hash binding, policyHash/commandSetHash, receipt identity, verifyAuthorityReceipt); the genuinely new parts are a portable bundle, an offline re-verifier, and the adversarial test. The contract-test result doubles as the paper's C2 data proof.

## Solution Tradeoffs
Scope this first slice to single-host, local-key-signed verification so it ships WITHOUT depending on the Authority server (cross-host Authority-signed verdicts are Tier-C, a deferred follow-up). Build on the existing verifier rather than a parallel re-implementation. The adversarial test enumerates a fixed tamper surface (code byte-flip, evidence edit, host-verdict swap, commandSet change, stale materialHash, forged/missing signature, missing build proof); it proves soundness over those enumerated classes, not a universal "uncrackable" claim — the bound is stated honestly.

## Conversational Texture
Capability slice 1 of the "tamper-evident, independently-verifiable autonomy" enhancement (designed in lattice-Paper/proofbound-wow-capabilities.md). Authority cross-host signing is explicitly out of scope here and is the second slice (which also closes the paper's Tier-C blocker). The contract-test output is intended to land in the paper's evidence-gating-spine section (C2) as the data proof that the anti-forgery binding is adversarially demonstrated, not merely described.
