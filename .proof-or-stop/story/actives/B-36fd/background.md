## Key Insights
The causal-validation gap the draft targets is real: the production hint-mode A/B assignment (resolveHintMode sha256-parity in packages/main/src/core/hint-mode.ts, consumed by experience-hint-surface.ts) covers only the review-entrypoint advisory hints, assigns per story, is trap-blind, computes no inferential statistics, and has accrued a single surfaced event — it cannot answer whether experience-layer consumption causally reduces defect recurrence. But the draft as written would produce an invalid result: (1) answer-key circularity — all six seeded trap classes have corresponding lessons stored verbatim in .lattice/learning/runtime-memory-pack-cache, so a positive result cannot be attributed to the surfacing mechanism without held-out negative-control traps; (2) store pollution — learning-store.ts resolveLearningRoot() canonicalizes linked git worktrees back to the single shared main-repo .lattice/learning store, so worktrees do NOT isolate experiment lifecycle writes; per-task non-git temp roots (the recovery-runner mkdtemp pattern) plus a frozen memory-pack snapshot are required; (3) fixture leakage — trap answers are independently derivable from the shared working tree (scripts/verify-lattice-residue.mjs is an executable oracle for the brand trap; CLAUDE.md/AGENTS.md state the host-policy and reviewer-lane answers verbatim), so per-trap answer-source stripping plus a fixture-leakage audit is needed. Sizing: the draft's single default parameter table (baseline 0.30, MDE 0.10) computes to 294/arm (588 tasks) but is calibrated for a live population; the claim-bearing seeded-trap population (plausible baseline 0.5-0.8, honest MDE 0.25-0.35) needs only 29-58/arm, and a full-factorial matched-pairs design (both arms on every fixture, McNemar) replaces 5-factor blocked randomization that yields under one task per cell. The draft also cites none of the existing infrastructure and allocates a redundant Shadow C arm although the production control arm already computes-and-logs the pack losslessly.
