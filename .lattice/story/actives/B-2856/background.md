## Trigger Event
On 2026-06-15 a ClawCreek user (Lattice CLI 0.3.5, wrapper-root layout: metadataRoot=/Users/jek/Documents/ClawCreek which is NOT a git repo, configured gitRoot=clawcreek) hit 'fatal: not a git repository' from lattice story_discard, validate --channel (git log main..story/B-bdbb) and validate --concept (git diff main...HEAD). Running the identical git commands from inside clawcreek/ succeeds, proving it is purely a cwd/gitRoot issue. Cross-checked in this session against B-bfb5's earlier mis-report and confirmed in source.

## Key Insights
The canonical resolver resolveStorySignedWorkspace() in core/story-signed-workspace-resolution.ts already computes authoritativeCwd = resolved gitRoot and is used by story_resolve (resolutionSource=configured-git-root). The defect is that ~14 git child-process sites bypass it and default cwd to projectRoot/root (the metadataRoot): validate-channel.ts (5 git reads), validate-concept.ts (git diff + repo-wide grep), cluster-sync.ts (git log main..HEAD), and worktree.ts story_discard + story_advance merge + remove/branchExists helpers. So the resolver knows the right root, but these consumers never ask it. The fix is mechanical re-routing through the existing dependency-injection seams in the readers, not a new resolver.

## Solution Tradeoffs
Approach A (chosen): resolve authoritativeCwd via resolveStorySignedWorkspace() at each handler entry and thread it into the readers (replacing projectRoot) and into the worktree.ts git()/execFileSync call sites, with a defined null/unresolved fallback to the current projectRoot/root so non-wrapper-root repos are byte-identical. Approach B (per-call git -C <root>) was rejected as scattering root logic and risking drift from the single resolver. Risk: a cwd regression could either keep blocking wrapper-root projects or, worse, make a gate falsely pass by running git against the wrong tree, so the null-fallback + a wrapper-root vs plain-repo test pair is mandatory. Strictly cwd-only: no change to command text, gate semantics, or bootstrap.
