## Trigger Event
On 2026-06-16, preparing Lattice for open-source release, the user required that no `koala` or `KOALA_` token remain in surfaces a user would encounter, because koala naming is hard to explain post-launch. A blast-radius scan found ~57 distinct KOALA_* env vars across ~595 occurrences; this story is the first substantive phase (the KOALA_* env layer) of the agreed 4-story ship-clean program (after B-ffa2 renamed active role IDs).

## Key Insights
The KOALA_* env vars split into two cases (verified by a corrected per-var twin scan, after the INIT reviewer caught an initial wrong claim): 17 already have a LATTICE_* twin with a dual-read fallback in code (e.g. registry.ts:289 `process.env.LATTICE_PROJECT_ROOT || process.env.KOALA_PROJECT_ROOT`; also LATTICE_GLOBAL_MEMORY_DIR, LATTICE_MD_TEMPLATE, LATTICE_STORY_DIR, LATTICE_REPAIR_IGNORE, LATTICE_RUNTIME_IGNORE_BLOCK_START/END, LATTICE_ACTIVITY_LOG, LATTICE_DIR, LATTICE_AUTHORITY_*). For those, removal = delete the `|| process.env.KOALA_X` fallback. The other 38 are KOALA-only (no LATTICE_ twin: KOALA_AGENT, KOALA_ROLE, KOALA_PHASE, KOALA_STORY_ID, KOALA_COMMAND, KOALA_ACTIVITY_SOURCE, etc.) and must be RENAMED to LATTICE_X across reads, setters (e.g. bin/lattice-codex.js sets KOALA_ACTIVITY_SOURCE), JSON configs, .Codex/.claude wrapper assets, hook-contract docs (docs/guide-hooks.md references KOALA_COMMAND/KOALA_NEW_PHASE), and the tests asserting them. Note: LEGACY_KOALA_* path CONSTANTS in core/lattice-paths.ts (.koala dir, legacy activity-log path) belong to the deferred .koala path work, NOT this env-var story.

## Solution Tradeoffs
No koala fallback is retained — for the 17 twins drop the `|| KOALA_X`; for the 38 KOALA-only rename to LATTICE_X. Keeping a dual-read shim would leave KOALA_ in code, violating the no-KOALA_ goal. This is an intentional breaking change (priority high): external shells/CI/Codex wrappers exporting KOALA_* must switch to LATTICE_*; acceptable pre-launch because there are no external users yet. The change is large but mechanical and cohesive; reviewability comes from a final residual scan asserting zero KOALA_ env names remain in code/config/wrappers. The docs/koala/legacy/ archive (12 files, 0 code refs) is dropped here as an easy side cleanup; active paths (.koala/, docs/koala/framework-audit) and historical data are deferred to later stories.

## Conversational Texture
The user is personally driving the open-source launch; shown that most koala occurrences are deliberate legacy-compat or truthful history, they chose the ship-clean depth and the env layer as the first substantive story, and accept that external env consumers must switch to LATTICE_*.
