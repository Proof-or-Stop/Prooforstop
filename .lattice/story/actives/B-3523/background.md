## Trigger Event
On 2026-06-20 the operator directed that the npm scope should be `@lattice` (the product is Lattice, not an 'agent'), not the current `@lattice-agent`. Scoping showed 68 live `@lattice-agent` references across 37 files. Separately, `docs/requirements/decisions/done-full-test-gate-execution-plan.md` (lines 16, 299) already flags that `.githooks/pre-push` self-host detection is keyed on the OLD package name `@koala-agent/core` while this repo is `@lattice-agent/core`, so the pre-push build+tsc gate silently exits early for this repo. The koala→@lattice-agent rename was an earlier koala-removal program step; this story completes the brand to `@lattice`.

## Key Insights
The live `@lattice-agent` surface (excluding frozen `.lattice/` audit metadata) is: 3 package.json `name` fields (`@lattice-agent/core` in packages/main, `@lattice-agent/utils` in packages/utils, `@lattice-agent/lab` in packages/lab) plus their inter-package `dependencies`; 27 internal imports (e.g. `from '@lattice-agent/core/dev-host'`, `'@lattice-agent/utils'`); self-host detection constants/checks `CANONICAL_CORE_PACKAGE_NAME` (runtime-environment-checks.ts, handlers/test-auto.ts, handlers/worktree.ts), `rollout-check.ts` (`mainPackageName === '@lattice-agent/core'`), and `codex-adapter-checks.ts` global-fallback candidates; the `.codex/hooks` + `.claude/hooks`; and docs (README.md, CLAUDE.md, CHANGELOG.md, a couple decision docs). Separately, `@koala-agent/core` survives as: the stale pre-push check; a legacy global-install fallback candidate in `codex-adapter-checks.ts` (the `@koala-agent/core` entry the operator saw in `codex verify`) plus test fixtures in `worktree-repair-smoke.ts` / `flow-stability-smoke.ts`; and anti-residue assertions in `scripts/verify-*.mjs` + the `verify-koala-residue.mjs` checker (these intentionally name the old scope to assert its ABSENCE and must keep doing so). The npm workspace resolves the three packages by scope; renaming requires a real `npm install` to regenerate `node_modules/@lattice/*` symlinks, then a rebuild, then re-running every self-host gate. Because the Lattice CLI itself is built from `@lattice-agent/core`, the rename is self-modifying: package.json, dist, bin resolution, and all self-host gates must flip to `@lattice/core` consistently or pre-push/codex-verify/rollout break.

## Solution Tradeoffs
Chosen: a single atomic scope rename `@lattice-agent` -> `@lattice` covering names + cross-deps + 27 imports + self-host constants/checks + hooks + docs, plus (a) fix `.githooks/pre-push` to `@lattice/core` (restoring its build+tsc gate) and (b) retire the legacy `@koala-agent/core` global fallback in `codex-adapter-checks.ts` and its test fixtures, leaving `@lattice/core` as the sole canonical global candidate. KEEP the anti-residue checkers (verify-koala-residue/runtime-fact/entrypoints) but update their expected canonical name to `@lattice/core` and have them also assert the absence of both `@koala-agent` and `@lattice-agent` live scopes. DECISION for PLAN: whether to keep `@lattice-agent/core` as a one-release migration fallback candidate (for users who installed the transitional scope globally) or drop it alongside `@koala-agent`; default lean is to drop both legacy candidates and document the clean break, since the global fallback is heartbeat-only and not a gate. DO NOT rewrite frozen `.lattice/` story audit records or `docs/koala/framework-audit/` history. The worktree must use a real `npm install` (NOT symlinked node_modules) so the new `@lattice/*` workspace links exist.

## Conversational Texture
The operator cares that the project presents as `@lattice` (the product name) end-to-end, and that the self-host gates (pre-push build+tsc, codex verify, rollout) actually work against the real package name rather than silently passing on a stale one. Acceptance focuses on: every live `@lattice-agent` and the legacy `@koala-agent/core` fallback gone (only frozen history + the intentional anti-residue assertions remain); the workspace installs/builds clean under `@lattice/*`; and the self-host gates (pre-push, `lattice codex verify`, `lattice rollout check`, full build+tsc) pass against `@lattice/core`.
