## Trigger Event
On 2026-06-17 a full-suite triage (test:all) on current main showed 140/162 (22 failing); standalone investigation of ~10 of them confirmed 0 production regressions and a dominant STALE-TEST category. The user chose to fix the ~13 stale tests first (P5 timeout family and B-6666 burndown deferred).

## Key Insights
The smokes rotted for the SAME root cause as the RED process-fact-contract: the 160-smoke suite was decoupled from the gate battery, so nobody ran it and the tests fell behind real, intentional behavior changes — the INIT_CHECK scope-boundary gate (init-check-* smokes), the B-097f host-neutral agent-prompt model (worktree-repair), the B-72df scoped dirty-main DONE clean-check (done-preflight), slug-casing normalization (story-dedup), the koala->lattice rename (lattice-cli-migration), and assorted message/text drift. Critically, the highest-stakes ones were confirmed NOT to be gate-bypasses: done-preflight leaves the story in TEST (not advanced to DONE) and worktree-authority's dirty-main edge passes standalone. So this is routine test maintenance, not an incident. The risk in this work is the inverse: a careless 'make it green' that weakens a test could mask a future real regression — hence the guardrail to update tests to assert correct behavior and escalate anything that turns out to be a real production bug.

## Solution Tradeoffs
Approach A (chosen): per-smoke, confirm the correct current behavior against production + the changing story, then update the test assertion/setup to match (e.g. init-check smokes set up scope-boundary.json; worktree-repair asserts the post-B-097f skip; done-preflight asserts B-72df scoped semantics; story-dedup expects the normalized slug; english-open-source-surface removes CJK from the offending test file). No production change. Approach B (delete/relax the failing assertions) is rejected — it hides behavior and could mask real regressions. Approach C (revert the behavior changes to satisfy old tests) is rejected — the behavior changes (scope-boundary gate, B-097f, B-72df) are intended and correct. Risk: mis-identifying a real bug as 'stale' and weakening a test — mitigated by the guardrail (confirm production correctness first; escalate genuine bugs) and by requiring each fixed smoke to pass standalone with its safety intent intact.
