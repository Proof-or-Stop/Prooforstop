## CHK-001 — Pure effectiveness leaf (core/experience-effectiveness.ts)
- imports only node:/types. Input type: ordered stories `[{ storyId, createdAt, hintMode?: 'on'|'off', findings: { signatureTag?: string; signatureTagSource?: string }[] }]` (already in temporal order, earliest first).
- `computePredictiveValue(stories, opts?)`: iterate in order; maintain `priorSignatures: Set<string>` (union of non-empty signatureTags from EARLIER stories). For each story: `preWarnable` = findings whose signatureTag ∈ priorSignatures; `recall` aggregate = total preWarnable / total findings-with-a-signature (or per design: preWarned/preWarnable — here every preWarnable finding IS by definition would-have-hinted, so report recall = preWarnable-with-known-sig / findings-with-sig, and precision = preWarnable / would-have-hinted where would-have-hinted = findings whose sig ∈ priorSignatures). Also a windowed trend (windows of N stories, hit-rate per window) + a simple slope sign. After processing a story, add its signatures to priorSignatures. Return { stories, findingsWithSig, preWarnable, recall, precision, windows:[{cutoff,hitRate}], slopeSign }. Never NaN (guard zero denominators -> 0). Optional opts.confirmedOnly to count only signatureTagSource==='confirmed'.
- `computeArmComparison(stories)`: group by hintMode ('on'/'off'/undefined-skip). Outcome per arm = mean over arm stories of (findings whose signatureTag was already in priorSignatures-at-that-story / findings-with-sig) — i.e. un-caught recurrence rate. Return { nOn, nOff, outcomeOn, outcomeOff, delta: outcomeOff-outcomeOn, significant, note }. significant = (nOn >= MIN_ARM_N && nOff >= MIN_ARM_N) ? <still conservative: only true if both arms meet N; do NOT compute a p-value, just gate on N and report delta> ... set significant=false with note 'insufficient N (need >= MIN_ARM_N per arm)' when N small. MIN_ARM_N a named const (e.g. 20). Never NaN; deterministic.
