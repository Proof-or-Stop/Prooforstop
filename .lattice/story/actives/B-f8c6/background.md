## Trigger Event
On 2026-07-04 the user approved starting M0 for the multi-model ablation replication protocol after clarifying that Codex CLI and other hosts may run in parallel only when registered as formal runners with locked model snapshots and cell manifests.

## Key Insights
M0 must prove that the experiment can be run fairly before any large token spend: host and model identity must be separated, E1 and E2 snapshots must be lockable, A2 prime budget calibration must precede A2 prime cells, and Codex CLI audit output must not be confused with ablation outcome data.

## Solution Tradeoffs
This story intentionally stops before Phase 1 data collection. It should add the canonical protocol document and lightweight readiness artifacts, not launch thousands of cells or change product gates. That keeps the work useful without optimizing for spectacle.

## Conversational Texture
The user wants speed from parallel hosts but also wants proof discipline: no arbitrary optimization, no mixed factors, no host-name based model claims, and no research evidence leaking into Proofbound runtime gates or playbooks.
