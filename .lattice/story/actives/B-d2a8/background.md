## Trigger Event
On 2026-06-20, the parallel-decomposition gate program (docs/parallel-decomposition-spec.md section 8) has Stories 0/1/2 merged: the frozen contract, the overlap engine, and the verdict (evaluateDecompositionGate, B-986c). AuditConfig.parallelGate is declared (Story 0) but resolveAuditConfig still does not populate it: its JSDoc literally says 'resolveAuditConfig populates it in Story 3'. So no operator config (mode / maxConcurrentReview / broadGlobBlocks) reaches the gate yet. This story resolves the config.

## Key Insights
The gate config is a NEW value set: mode is advise|block|off, disjoint in meaning from AuditMode (semi-auto|full-auto|off; they only share off), so VALID_MODES (typed ReadonlySet<AuditMode>) cannot validate it. spec section 4.7 defines a separate VALID_PARALLEL_MODES (already exported by parallel-decomposition.ts) with an advise fallback. Crucially, parallelGate is a NESTED object, but the existing per-scalar override path in resolveAuditConfig does NOT recurse into nested objects, so copying the flat pattern would silently skip every sub-field check. A dedicated resolveParallelGate helper must validate each sub-field (mode, maxConcurrentReview, broadGlobBlocks) with its own guard and fallback. Per-profile defaults: light advise/2/false, balanced advise/3/false, strict block/4/true.

## Solution Tradeoffs
Add the per-profile default table plus resolveParallelGate to core/audit-config.ts only (disjoint from Story 4 lattice-parallel-wave.ts/story-review.ts and Story 5 machine.ts/parallel-decomposition.ts). Reuse the existing positive-integer guard pattern (from auditTriggerWindow/deprecatedGcThreshold) and the existing readUserConfig + console.warn fallback discipline, so config-load failures fail SOFT to profile defaults (a config error must never DoS). Import the value set VALID_PARALLEL_MODES and the type ParallelGateConfig from parallel-decomposition.ts (single source).

## Conversational Texture
The operator wants the parallel-decomposition gate to be configurable per profile and per project, with the strict profile hard-blocking broad globs while light/balanced only advise, and a reversible off escape hatch. This story wires that configuration through, with full Claude plus Codex dual-host (full-3x2) per the program standard; the operator cares that a malformed config never crashes resolution (it falls back, warns once).
