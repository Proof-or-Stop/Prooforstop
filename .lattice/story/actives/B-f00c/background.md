## Trigger Event
During story B-3783's TEST->DONE convergence on 2026-07-25/26, the ~17 min build+npm-test DONE-required validation ran 3-4 times against identical material. One re-run was forced by done_prepare refusing to reuse a validation it had just produced: refusalReasons=untrusted-lineage-path:lattice.config.json,untrusted-lineage-path:packages/main/src/tasks/command-catalog-smoke.ts while priorIdentityDigest===currentIdentityDigest (a21a13de...). A cross-host audit (Claude CLI 2.1.220 + Agy CLI 1.1.7, both SOUND-WITH-CHANGES) confirmed the root cause and expanded the scope. Spec: docs/done-validation-reuse-merge-lineage-fix-proposal.md.

## Key Insights
classifyTrustedValidationLineage (packages/main/src/core/validation-evidence-reuse.ts:251) computes changed files as a UNION of per-commit `git diff-tree -m` outputs. The -m flag expands a merge commit into a diff against EACH parent; a main merge lists the story's own content-unchanged files against the main parent, which are then flagged untrusted-lineage-path, so reuse is refused even though materialHash, storyFilesHash and identity.digest are all identical. A byte-equivalent second copy validationHeadLineage (packages/main/src/core/validation-evidence-admissibility.ts:42) feeds assessStoredValidationPassAdmissibility, which hard-throws inside autopilot_review_submit --deriveBindings (packages/main/src/handlers/verdict.ts:139), so the same false positive also blocks the quorum-floor submission during the hot-main closeout.

## Solution Tradeoffs
Replace the per-commit -m union with a net endpoint diff (git diff-tree -r evidenceHead currentHead): a merge that re-touches a content-unchanged file no longer lists it, while a genuinely content-changed non-metadata file still refuses reuse because content identity equals validation identity. Harden per audit: -z NUL split for spaced/non-ASCII paths, explicit large maxBuffer (ENOBUFS precedent B-f492 in evidence-freshness.ts:121), empty-net-diff means trusted (not rejected), and split the ancestry-vs-diff catch so an ENOBUFS/diff failure is not mislabeled as a non-ancestor. Extract ONE shared helper used by BOTH copies so they cannot diverge again. Do NOT relax the genuine-receipt gate (isReusableCommandPass), the material/storyFiles/identity hash factors, refresh_stale laundering (B-3b88 domain), or the review assurance floor.
