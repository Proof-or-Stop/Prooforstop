## Trigger Event
On 2026-07-14, B-3b05 done_prepare blocked at validate with FAIL root full test suite: npm test exitCode=1. Isolation traced it to test:brief-output asserting doctor brief under 20000 bytes but getting 20239. A byte-level diff of the fixture doctor output captured on the main checkout versus the B-3b05 worktree showed exactly one meaningful delta: the global-core-realpath row flips from a one-line pass to a warn with two extra lines (mismatch detail naming .worktrees/B-3b05/packages/main as expected path, plus a Relink or reinstall repair hint). B-9188 passed the same DONE-required suite from a worktree on 2026-07-13, so recent main growth in doctor brief output brought the worktree case over the budget line.

## Key Insights
The global lattice binary intentionally resolves to the repository canonical main checkout (documented operating practice: rebuild canonical packages/main dist after merges; worktrees install their own node_modules but never relink the global CLI). Therefore global realpath equal to the main checkout while running in a linked worktree is the EXPECTED state, not a defect; the check as written can never pass inside any worktree. The 20000-byte brief budget in brief-output-smoke is a legitimate UX guard from B-7c05 and should stay; the false warn is the thing to remove. npm test sits in the DONE-required command set, so this single false warn transitively blocks DONE for all worktree stories.

## Solution Tradeoffs
Preferred: teach the global-core-realpath check to detect linked-worktree context (git worktree metadata or git rev-parse --git-common-dir differing from --git-dir) and treat global-resolves-to-canonical-main-checkout as pass/info without a repair block, keeping the genuine unrelated-path mismatch warn. Alternatives rejected: raising the smoke byte budget hides the false positive and erodes the brief UX guard; relinking global @lattice/core per worktree contradicts documented practice and breaks other worktrees; removing the check entirely loses real mismatch detection.

## Conversational Texture
This story exists to unblock B-3b05 and every other in-flight worktree story cleanly rather than bending B-3b05 scope to patch infrastructure. Acceptance from the operator chair: lattice doctor run inside a linked worktree shows no global-core-realpath warn and no relink advice, npm test goes green from a worktree, and a genuine global-CLI mismatch (pointing at an unrelated path) still warns.
