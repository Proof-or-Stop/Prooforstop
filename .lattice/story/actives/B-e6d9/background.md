## Key Insights
The current Story gate should consume only Findings that are authoritative, fresh, current-scope applicable, and blocking. A separate mandatory-repair floor must override deferral for severe defects, current-change regressions, data or security risk, historical evidence damage, release paths, CLI entrypoints, and lifecycle gates.

## Solution Tradeoffs
Introduce signed assessments, explicit verdict and routing, defer-with-proof receipts, expiry and re-attestation, batch manifests, one shared blocking predicate, scorecards, and kill switches. This adds evaluation work, but bounded assessment is cheaper and safer than forcing every unrelated Finding into the current Story or silently dropping debt.
