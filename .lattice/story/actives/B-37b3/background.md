## Trigger Event
On 2026-06-20, `learning_effectiveness` reported the Experience Layer ON/OFF arm as nOn=2 / nOff=0 (no measurable effect) despite the full layer being built (B-000c/B-1dc9). Root cause found: the derived finding-signals cache `.lattice/learning/finding-signals.json` is a gitignored artifact that exists ONLY in the main checkout, but every story DEV/REVIEW runs inside a git WORKTREE (.worktrees/B-xxxx/) where that cache is absent — so `loadExperienceHints(ctx.root)` reads `${worktreeRoot}/.lattice/learning/finding-signals.json`, finds nothing, and `story_review` never surfaces hints nor fires `experience_hint_surfaced`. The Experience Layer is structurally disconnected from the worktree-based workflow.

## Key Insights
core/learning-store.ts is "the ONLY code that touches .lattice/learning/" and resolves the dir relative to the passed project root (LEARNING_DIR = .lattice/learning). When story_review runs in a worktree, ctx.root is the worktree path, so the cache (written by learning_scan in the main checkout) is unreachable. `git rev-parse --git-common-dir` from a worktree returns the main repo .git (e.g. ../../.git); its parent directory is the canonical MAIN worktree root, where the single cache should live and be read from. Verified: from .worktrees/B-xxxx the resolved main root reaches the 332KB cache. Confirmed NO worktree carries its own copy.

## Solution Tradeoffs
Resolve the learning-store cache root to the MAIN repo root (parent of `git rev-parse --git-common-dir`) for BOTH reads (loadExperienceHints / learning_validate / learning_effectiveness) and writes (learning_scan), so one canonical cache in the main checkout is reachable from every worktree. MUST fall back to the passed root when git resolution fails (non-git temp dirs used by smokes, or any error) so existing tests and plain layouts stay byte-identical. Advisory-only, touches no gate; do not change the cache schema or the finding-signals derivation. REJECT copying/symlinking the cache into each worktree (duplication + staleness + cleanup hazard) — a single canonical cache resolved by git-common-dir is simpler and always fresh.
