## 如何控制验证本身的耗时

优先复用已有且未失效的正确性证据，先准备计时账本和少量因果反例，再按试跑收益进入完整对照。按旧 45.27 分钟单臂估算，一次完整配对约 90.54 分钟，六对约 9.05 小时/主机；这是成本预算参考，不能冒充新基线。模型审查的大样本活动还需在试跑后冻结调用数、时间及费用上限。

本轮没有启动全量性能活动。第二台机器和真实 Story 后续观测仍需相应外部条件，不能在单个 Lab 内虚构完成。
